Developer API Documentation

Integrate DeepShield's neural forensic detection engine directly into your applications.

POST /api/detect

Analyzes a single image file for synthetic artifacts, returning forensic metrics and confidence classification.

cURL Example:

curl -X POST http://127.0.0.1:5000/api/detect \ -F "image=@/path/to/image.jpg"

Python Example:

import requests files = {'image': open('sample.jpg', 'rb')} response = requests.post('http://127.0.0.1:5000/api/detect', files=files) print(response.json())

Sample JSON Response:

{ "status": "success", "filename": "sample.jpg", "result": "AI Generated / Synthetic", "confidence": "75.0%", "is_ai": true, "ela_std_dev": 3.31, "fft_high_freq": 120.22, "metadata_flags": ["No camera EXIF metadata present"] }

POST /api/batch-detect

Batch inspects multiple image files concurrently in a single HTTP request payload.

Python Batch Example:

import requests files = [ ('images', open('img1.jpg', 'rb')), ('images', open('img2.png', 'rb')) ] response = requests.post('http://127.0.0.1:5000/api/batch-detect', files=files) print(response.json())
