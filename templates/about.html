DeepShield Forensic Architecture

Our multi-layered inspection engine combines digital signal processing, spatial frequency analysis, and metadata verification to detect AI-generated artifacts.

Error Level Analysis (ELA)

Analyzes JPEG compression error rates across image regions. AI synthetic imagery often exhibits uniform or anomalous ELA variance compared to optical camera sensors.

Compression Heatmaps Standard Deviation Pixel Difference

2D Fourier Transform (FFT)

Converts spatial pixel signals into the frequency domain (`np.fft.fft2`) to expose high-frequency grid artifacts left by Latent Diffusion & GAN upsampling layers.

Frequency Domain GAN Artifacts Spectral Energy

EXIF Provenance Scanner

Inspects binary image headers for software generator signatures (Midjourney, DALL-E, ComfyUI, Automatic1111) and camera EXIF metadata indicators.

EXIF Audit Generator Signatures Metadata Signals

Persistent Audit Logger

Stores every inspection result, timestamp, and quantitative metric in a local SQLite database (`scans.db`) for tracking audit history over time.

SQLite Database Audit Logs Historical Reports

REST API & Batch Detection

Provides JSON endpoints (`/api/detect` and `/api/batch-detect`) allowing developers to programmatically scan single images or multi-file batches.

REST Endpoints Batch Processing JSON API
